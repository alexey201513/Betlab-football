# BetLab Football — первая версия

## Что уже работает
- Тёмный мобильный интерфейс.
- Виртуальный и реальный банки с отдельными балансами.
- Индивидуальная сумма и коэффициент для каждого прогноза.
- Одиночные прогнозы и экспрессы (экспресс записывается одной карточкой с общим коэффициентом).
- Рынки: исходы, угловые, карточки, голы, удары, форы и другие.
- Ввод результата вручную, расчёт прибыли, проходимости и ROI отдельно для виртуального и реального банков.
- Незавершённые ставки резервируют сумму в доступном балансе; возвраты исключены из оборота ROI и расчёта проходимости.
- История, поиск, фильтры, аналитика по рынкам и коэффициентам.
- Пополнения и снятия банков.
- Экспорт и импорт резервной копии JSON.
- Локальное хранение на устройстве и базовый офлайн-кэш.
- Иконки PWA 192×192 и 512×512 для установки на главный экран.

## Как открыть на Android прямо сейчас
1. Распакуйте ZIP.
2. Откройте `index.html` в браузере телефона для ознакомления. Некоторые браузеры ограничивают установку PWA при открытии локального файла.
3. Для установки как приложения опубликуйте папку на HTTPS-хостинге (например, GitHub Pages) и откройте ссылку в Chrome на Android.
4. В меню Chrome выберите «Установить приложение» или «Добавить на главный экран».

## Важно
Это первая автономная версия-прототип в формате PWA, а не подписанный APK. Автоматическое получение расписаний и статистики пока не подключено: для этого требуется выбранный внешний API и ключ доступа. В этой версии результаты вносятся вручную. Данные хранятся локально в браузере; используйте экспорт резервной копии.
