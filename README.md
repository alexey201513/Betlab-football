# BetLab Football 2.0

Мобильный журнал футбольных прогнозов/ставок с PWA и Android-обёрткой.

## Что исправлено
- В «Добавить прогноз» появились выбор лиги и команды.
- Для одиночного прогноза матч собирается из выбранных команд.
- Для экспресса можно добавлять **2, 3, 4 и больше матчей** отдельными карточками.
- У каждого события экспресса своя лига, дата, команды, рынок, выбор и коэффициент.
- Общий коэффициент экспресса рассчитывается автоматически.
- Старый формат данных `localStorage` сохраняется.
- Добавлен Android WebView-проект.
- Добавлен GitHub Actions workflow для сборки APK.

## Важно про реальные матчи
Сейчас справочник лиг и команд встроен в приложение. Он нужен для удобного выбора, но это **не онлайн-расписание**. Для автоматической загрузки актуальных матчей, туров, составов и статистики нужен футбольный API и его ключ.

## GitHub Pages / PWA
Публикуй содержимое папки `BetLab_Football` на HTTPS. PWA можно установить через Chrome на Android.

## APK через GitHub
1. Загрузи весь проект в GitHub.
2. Открой **Actions → Build Android APK → Run workflow**.
3. После завершения открой созданный artifact `BetLab-Football-debug`.
4. Внутри будет `app-debug.apk`.

Для Google Play потребуется release-сборка и подпись APK/AAB собственным ключом.

## Реальные футбольные данные через API-Football

В проект добавлен `worker/` — Cloudflare Worker-прокси. API-ключ хранится в Cloudflare Secret и не попадает в APK.

1. Открой `worker/README.md`.
2. Установи Wrangler и выполни `wrangler login`.
3. В `worker/` выполни `wrangler secret put API_FOOTBALL_KEY`.
4. Выполни `wrangler deploy`.
5. Скопируй URL Worker с `/api`.
6. В BetLab открой **Ещё → Банки и настройки → Онлайн-футбол**, вставь URL и нажми **Проверить API**.

После этого приложение сможет получать реальные лиги, команды и матчи. При смене API-ключа APK пересобирать не нужно — меняется только Secret на Worker.
